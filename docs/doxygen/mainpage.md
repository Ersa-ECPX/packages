# Ersa Compute Platform: C++ components

The compiled parts of the Ersa Compute Platform, documented from their sources at the commits the packages are built from.

- **ersa-bluetooth** ([overview](md_pages_2ersa-bluetooth.html), [D-Bus API](md_ersa-bluetooth_2docs_2DBUS__API.html)): `ersa-bluetoothd` is a D-Bus bridge that unifies BlueZ device management, AVRCP media control, HFP call control, phonebook access and Apple notifications behind one stable API.
- **Dialer** ([overview](md_pages_2dialer.html)): a phone dialer for GNOME, built with GTK 4 and libadwaita. It is a client of `ersa-bluetoothd`.

Browse the code by [classes](annotated.html), [files](files.html) or [namespaces](namespaces.html). The code has no Doxygen comments yet, so the
reference shows structure and the Markdown documents, not prose.
